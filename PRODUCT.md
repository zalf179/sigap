# Product

<!-- impeccable:product-schema 1 -->

## Platform

web

## Stack

Vite + React + React Router + Tailwind CSS (Frontend), Node.js + Express (REST API), MySQL (Database)

## Users

- **Warga (residents)** - Household members who need to identify waste types, report issues, view waste pickup schedules, and access educational articles
- **Petugas (officers)** - Field officers who handle and process waste-related reports from residents
- **Admin** - System administrators who manage users, articles, schedules, categories, and view statistics

## Product Purpose

SIGAP (Sistem Informasi Tanggap Darurat dan Edukasi Pengelolaan Sampah Perumahan Berbasis Web) is a web-based information system for emergency response and waste management education in residential areas. It enables residents to properly identify and sort waste, report waste management issues, stay informed about pickup schedules, and access educational content about waste management.

## Positioning

A comprehensive residential waste management platform that combines waste identification education, issue reporting, scheduled pickup information, and administrative oversight in one integrated web system tailored for housing communities in Indonesia.

## Operating Context

- Used in Indonesian residential communities (perumahan)
- Day-to-day waste management coordination between residents and officers
- Mobile/web accessible for residents reporting from home/neighborhood
- Officers handle reports in the field/office
- Admin manages system configuration and monitors overall operations

## Capabilities and Constraints

- **Waste identification**: Tool to help residents identify types of waste
- **Issue reporting**: Residents can create reports with photos and descriptions
- **Report tracking**: Residents can view status of their reports; officers/admins can process them
- **Pickup schedules**: Block-based waste pickup schedule information
- **Educational articles**: Public articles about waste management
- **User management**: Role-based access (warga, petugas, admin)
- **Statistics & reporting**: Admin can view stats and export reports (Excel/PDF)
- **File uploads**: Support for images in reports
- Indonesian language interface

## Brand Commitments

- Name: SIGAP
- Language: Indonesian (Bahasa Indonesia)
- Focus: Practical waste management for residential communities
- Tone: Informative and service-oriented

## Evidence on Hand

- Full working web application (frontend + backend)
- Database schema with users, reports, articles, schedules, categories, blocks
- Seeded admin and petugas accounts
- Upload functionality for images
- Export capabilities (Excel/PDF)

## Product Principles

1. **Practical utility** - Focus on everyday waste management tasks residents actually need
2. **Clear communication** - Make it easy for residents to report issues and understand status
3. **Role-appropriate access** - Different interfaces for residents, officers, and admins
4. **Education through information** - Combine action (reporting) with knowledge (articles, identification)
5. **Local context** - Designed for Indonesian residential communities with local terminology and workflows

## Accessibility & Inclusion

- Role-based access control for different user types
- Clear status indicators for reports
- Simple, straightforward navigation
